# Sales Email Persona

> 세일즈 개인별 또는 팀 표준의 이메일 톤/문구 가이드. `/followup`이 이메일 초안 작성 시 선택적으로 참조.
> 없어도 작동하지만, 있으면 진짜 그 세일즈가 쓴 것처럼 자연스러운 톤으로 생성됨.

## 작성자

- **이름**: [세일즈 이름]
- **역할**: AE / SDR / CSM / 기타
- **언어**: 한국어 / 영어 / 일본어 / 기타
- **고객 산업**: [B2B SaaS / 핀테크 / 미디어 / 기타 — 영향 있는 경우]

## 톤

- **격식**: 공손-격식 / 공손-친근 / 친근-비격식 / 격식-격식
- **이모지**: 사용 / 미사용 / 상황별
- **인사말 기본형**:
  - 첫 미팅 후: [예: "어제 미팅 시간 내주셔서 감사합니다."]
  - 후속 미팅 후: [예: "오늘도 시간 내주셔서 감사합니다."]
- **마무리 기본형**:
  - [예: "추가 질문이나 다른 분 소개가 필요하시면 언제든 답장 주세요."]
  - [예: "감사합니다."]
- **사인오프**:
  - [예: "[이름] 드림"]
  - [예: "Best regards, [이름]"]

## 문체 규칙

- **존댓말**: 항상 / 상대 직급에 따라 / 친밀도에 따라
- **문장 길이**: 짧게 / 보통 / 길게
- **불릿 사용**: 적극 / 최소 / 미사용
- **이모티콘**: 사용 / 미사용

## 자주 쓰는 표현

| 상황 | 선호 표현 |
|---|---|
| 다음 단계 합의 강조 | [예: "합의된 다음 단계를 다시 한 번 정리드립니다."] |
| 자료 송부 안내 | [예: "추가로 보내드리는 자료입니다."] |
| 일정 조율 요청 | [예: "혹시 다음 주 중 30분 정도 시간 가능하실까요?"] |
| 결정 push (정중하게) | [예: "[날짜]까지 회신 주시면 [후속 일정]을 잡기에 충분할 것 같습니다."] |

## 피해야 할 표현

- [예: "확인 부탁드립니다" — 다소 강압적으로 들림. "확인 후 회신 주시면 감사하겠습니다"로]
- [예: 영어 표현 직역 — "let me know" → "알려주세요" (자연스러움)]
- [예: 과도한 마케팅 용어 — "혁신적", "차별화된", "유일한"]

## 인용/CC 정책

- **CC 기본**: [예: 내부 매니저 + SE]
- **고객 측 추가 CC**: [예: 미팅 참석자 전원]
- **고객 발언 인용 시**: 따옴표 사용 / 본인 말로 paraphrase

## 길이 가이드

- **첫 미팅 후 follow-up**: 200–300자
- **demo 후 follow-up**: 300–500자
- **closing 단계**: 200자 + 첨부 자료 강조
- **rejection 후 nurture**: 100–150자 (가볍게)

## 샘플 이메일 (있으면 가장 좋음)

> 실제로 본인이 보낸 이메일 1–2건 샘플로 첨부. AI가 톤을 학습.

```
[샘플 이메일 1 — 실제 발송한 follow-up]
```

```
[샘플 이메일 2]
```

## 사용법

1. 본 파일을 `docs/sales_email_persona.md` (또는 세일즈별 `docs/personas/<이름>.md`)에 저장
2. `/followup` 실행 시 자동으로 발견하여 참조
3. 또는 명시적으로: `/followup <meeting_notes> --persona docs/personas/김지원.md`
