## Critical Flows

1. **Hooks never crash a session** — every hook code path must exit 0 (fail-soft contract). Corrupt or missing state files → rebuild/skip, never raise.
2. **Generated skills match templates** — any SKILL.md edit must go through the `.tmpl` + `gen_skills.py` regeneration; CI's `--dry-run` gate fails on divergence.
3. **Checkpoint discipline** — blocking gates stop pipelines on non-zero exit; advisory gates print `ADVISORY:` and continue.
