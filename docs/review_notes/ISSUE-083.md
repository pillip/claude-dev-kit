- **[Medium] A `git branch --track` failure escapes resolve_from_remote without any reason= line — and it is REACHABLE, contrary to this reviewer's first assessment**
  Evidence: scripts/worktree.sh:193 `git branch --quiet --track "$branch" "origin/$branch"` is the function's last command, and the function is called as `resolve_from_remote "$branch" || return 1` (:250) — a `||` context, which suppresses `set -e` inside the callee, so its status becomes the return value with no refusal printed.
