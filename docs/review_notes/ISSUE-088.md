- **[Medium] test_an_unmeasurable_trade_off_is_refused computes a splice bound it never uses, so its 'mutation did not apply' guard is tautological**
  Evidence: tests/test_spec_088_decision_contract.py:119-132 (committed). `tradeoff_end` is computed at :128 and used only inside the :130 assertion. The mutation at :129 is `text[:start] + body[:tradeoff_start] + vague + text[end:]`, which discards everything from the trade-off to the end of Option C rather than replacing only the trade-off. So `assert body[tradeoff_start:tradeoff_end] not in mutated` is absent by construction whether or not the surgical replacement happened — precisely the un-mutation-tested absence guard this repo's own review lesson warns about.   Fix: FIXED IN REVIEW.
